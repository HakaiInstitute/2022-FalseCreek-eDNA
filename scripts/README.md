The objective of these four scripts are standardize the eDNA metabarcoding and DNA barcoding data to Darwin Core, and integrate them. When replicating the DwC data tables, it is recommended to run the scripts sequentially.

🧬 Step 1: 01.1-3_FCBB_*_taxonomy_cleaning.R -- these scripts clean the 12S, 16S and COI taxonomy files, making sure that the _scientificName_ matches the lowest known taxonomic information available for a given ASV, and matching it to a WoRMS AphiaID (scientificNameID). Some species names include strings with numbers and letters (e.g., "Glycinde sp. BCPOL601-10"), so we want to make sure that we capture this original recording of the name while at the same time providing taxonomic information for the lowest known rank (Glycinde). The cleaned, WoRMS-matched, output .csv files are found in their respective folder under `data/metabarcoding/`. 

🧬 Step 2: 02_eDNA_metabarcoding_to_dwc.R -- this script standardizes the metabarcoding data from the False Creek BioBlitz. Three different target genes (12S, COI and 16S) were used in the processing and are integrated into the following Darwin Core tables: event Core, occurrence extension, DNA Derived data extension, and eMOF. This script use the cleaned, WoRMS-matched, output .csv files from scripts 01.3-FCBB_*_taxonomy_cleaning.R (see above). The outputs from this script are stored under the `obis/interim_obis/edna` folder because they are not the final Darwin Core tables published to OBIS (as they have not been integrated with the data from BoLD yet).

🧬 Step 3: 03_BoLD_DNA_barcoding_to_dwc.R -- during the BioBlitz there were also organisms captured and sampled for their DNA. This DNA barcoding data was uploaded to the Barcode of Life Data System (BoLD) [here](https://portal.boldsystems.org/recordset/DS-FCBB). In this script, the data table (.xlsx) downloaded from BoLD is parsed out into separate Darwin Core data tables to facilitate the integration with the eDNA metabarcoding Darwin Core tables (script 02). 🥇 Step 4: 04_combining_dwc_tables.R -- The DwC tables generated from scripts 02 and 03 are integrated in this script and QAQCd. The resulting Darwin Core files are stored in the `obis` folder and published to OBIS.
