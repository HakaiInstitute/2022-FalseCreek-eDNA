The objective of these four scripts are standardize the eDNA metabarcoding and DNA barcoding data to Darwin Core, and integrate them. When replicating the DwC data tables, it is recommended to run the scripts sequentially.

01_FCBB_COI_taxonomy_cleaning.R -- this script cleans the [FC_taxonomy_COI_Revised_June2025.csv file](https://github.com/HakaiInstitute/2022-FalseCreek-eDNA/blob/obis-dwc/data/metabarcoding/COI/FC_taxonomy_COI_Revised_June2025.csv), making sure that the _scientificName_ matches the lowest known taxonomic information available for a given ASV, and matching it to a WoRMS AphiaID (scientificNameID). Some species names include strings with numbers and letters (e.g., "Glycinde sp. BCPOL601-10"), so we want to make sure that we capture this original recording of the name while at the same time providing taxonomic information for the lowest known rank (Glycinde). The output of this script is the **FC_taxonomy_COI_worms.csv** file.

02_eDNA_metabarcoding_to_dwc.R -- this script standardizes the metabarcoding data from the False Creek BioBlitz. Three different target genes (12S, COI and 16S) were used in the processing and are integrated into Darwin Core tables. These are stored under the obis/interim_obis/edna folder because they are not the final Darwin Core tables published to OBIS.

03_BoLD_DNA_barcoding_to_dwc.R -- during the BioBlitz there were also organisms captured and sampled for their DNA. This DNA barcoding data was uploaded to the Barcode of Life Data System (BoLD) [here](https://portal.boldsystems.org/recordset/DS-FCBB). From BoLD, we downloaded the DwC table and manually added in the geographic coordinates where a sample (organism) was captured. In this script, the DwC data table (.csv) downloaded from BoLD is parsed out into separate Darwin Core data tables to facilitate the integration with the eDNA metabarcoding Darwin Core tables (script 02). The data tables are stored under obis/interim_obis/bold before they get integrated with the eDNA metabarcoding DwC tables.

04_combining_dwc_tables.R -- The DwC tables generated from scripts 02 and 03 are integrated in this script and QAQCd. The resulting Darwin Core files are stored in the `obis` folder and published to OBIS.
