## Data

This folder contains the source files from the False Creek BioBlitz eDNA survey (`metabarcoding`), overall project metadata (`FC_metadata`), and a species_list.csv file. The `metabarcoding` folder contains three subfolders: `12S`, `16S` and `COI` with the respective source data files from each of those target genes used in the standardization process. It also contains a sample_metadata file.
