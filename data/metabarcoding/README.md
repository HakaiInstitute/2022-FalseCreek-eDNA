This folder contains the source files for the metabarcoding work done following the eDNA sampling. The root of this folder contains the sample metadata (i.e., sampleID, depth, filter volume, collection date, location and geographic coordinates). The water samples were processed with three target genes: 12S, COI and 16S, which have their subfolders. Each subfolder contains three .csv files and one .fasta file:

* A taxonomy file: Each ASV has associated taxonomic information.
* A sequence file: The DNA sequence associated with each ASV.
* An ASV data table: The number of DNA reads for each ASV within a sample.
* A metabarcoding metadata file: This file contains additional sampling metadata that is (highly) recommended for publication to OBIS.
